# Magic — демо-версия сайта

Статический сайт из одного файла: `index.html` (стили и скрипты встроены).
Внешние зависимости — только шрифты Google Fonts.

## Локальный запуск

    python3 -m http.server 8000

Открыть http://localhost:8000

## Деплой на Render

Static Site, ветка `main`, Build Command — пустая, Publish Directory — `.`
Настройки продублированы в `render.yaml`.

## Важно

Цены, реквизиты и контакты демонстрационные. Перед публикацией на реальном
домене их нужно заменить, а тексты согласовать с юристом (ФЗ-15, ФЗ «О рекламе»).
